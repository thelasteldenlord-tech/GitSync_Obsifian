    Project One 
        - The Idea/Goal: "Font Add On APK" - (Samsung Galaxy S24 Ultra). The idea struck when browsing the immense volume of font addons available in the galaxy store, and it occurred to me, that if there are this many apps selling access to fonts that it must bear to reason it's easier than ever to make an app, so I decided to tackle my first Android APK with the help of some of my favorite AI tools, Claude Code, Google Antigravity, Copilot, and more. It will require that we develop an installable APK file and I will have to lean into AI code agents entirely for the development and testing. I will begin with Copilot as it is free, saving my paid time with Claude Code for the actual brainpower, as Claude is scary good at any coding tasks. Other tools we will need to use are as below, based entirely on what I have available. I'm confident that this can be done, though I believe it will require a device that comes shipped with support for such fonts.
