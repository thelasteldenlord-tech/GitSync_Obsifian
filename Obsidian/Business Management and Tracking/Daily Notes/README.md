# Daily Notes

> Daily journal and task tracking system

---

## Purpose

Daily notes help you:
- Track daily activities and accomplishments
- Plan priorities and tasks
- Document client interactions
- Capture ideas and insights
- Review progress over time
- Maintain momentum

---

## How to Use

### Creating a Daily Note

1. **Create a new note** for each day: `YYYY-MM-DD.md`
   - Example: `2025-10-28.md`

2. **Use the template**: [[Daily Note]]
   - Copy the template content
   - Paste into your new daily note
   - Fill in the placeholders

3. **Complete throughout the day**:
   - Start with priorities
   - Update as you complete tasks
   - Document interactions
   - Capture random thoughts

### Daily Routine

**Morning (Start of day)**:
- [ ] Create today's note
- [ ] List top 3 priorities
- [ ] Review schedule
- [ ] Plan calls/meetings

**During Day**:
- [ ] Document client interactions
- [ ] Note completed tasks
- [ ] Capture ideas
- [ ] Track time spent

**Evening (End of day)**:
- [ ] Review accomplishments
- [ ] Plan tomorrow's priorities
- [ ] Note any follow-ups needed
- [ ] Reflect on wins and challenges

## Organization

### File Naming
Use ISO date format: `YYYY-MM-DD.md`
- Example: `2025-10-28.md`
- Sorts automatically
- Easy to find
- Unambiguous

### Linking
- Link to client files: `[[Client Name]]`
- Link between days: `[[2025-10-27|← Yesterday]]`
- Link to resources: `[[Meeting Notes]]`

## What to Track

### Essential Daily Items
- **Top priorities** - What MUST get done today
- **Client interactions** - Calls, meetings, emails
- **Tasks completed** - What you accomplished
- **Tomorrow's plan** - Set yourself up for success

### Optional Items
- Schedule and time blocks
- New leads discovered
- Ideas and insights
- Challenges faced
- Energy levels
- Financial activity

## Benefits

### Short-term
- Stay organized daily
- Don't forget tasks
- Document interactions
- Track progress

### Long-term
- Review patterns over time
- See what works (and doesn't)
- Document business growth
- Create historical record
- Improve planning

---

## Tips for Success

### Make it a Habit
- Do it at same time each day
- Keep it simple (don't overcomplicate)
- Be consistent
- Review weekly

### Keep it Practical
- Don't aim for perfection
- Some days will be sparse
- Focus on what's useful
- Adjust template to your needs

### Link Liberally
- Link to client files
- Link to projects
- Link to templates
- Create connections

---

## Weekly Review

Every week, review your daily notes:
- What got accomplished?
- What patterns emerge?
- What worked well?
- What needs adjustment?
- What priorities for next week?

---

## Monthly Review

Every month, scan all daily notes:
- Major accomplishments
- Client interaction frequency
- Task completion rates
- Energy and productivity patterns
- Lessons learned
