# Client Access Policy

**Effective Date**: 2025-10-28
**Last Updated**: 2025-10-28
**Next Review**: 2026-01-28

---

## Purpose

This policy establishes procedures and requirements for accessing client properties, equipment, and resources. It ensures we have proper authorization and documentation for all access, protecting both our business and our clients.

---

## Scope

This policy applies to:
- All employees and contractors accessing client properties
- All types of client access (scheduled, emergency, maintenance)
- All client resources (buildings, equipment, systems, data)
- All service locations

---

## Core Principle

**Never access client property or resources without explicit, documented authorization.**

---

## Authorization Requirements

### Before Any Access

Every client engagement requires:

1. **Written Authorization**
   - Signed service agreement or contract
   - Scope of access clearly defined
   - Authorized areas specified
   - Duration of authorization
   - Emergency contact procedures

2. **Access Documentation**
   - Copy stored in client file
   - Digital backup maintained
   - Access log established
   - Key/code inventory created

3. **Client Verification**
   - Confirm authorization with client contact
   - Verify access instructions
   - Document verification date and method
   - Update contact information

## Access Procedures

### Before Each Visit

1. **Review Authorization**
   - Confirm current contract/authorization
   - Check for access restrictions or changes
   - Review authorized areas
   - Note any special instructions

2. **Verify Schedule**
   - Confirm appointment (if required)
   - Check client availability
   - Note any property restrictions
   - Plan arrival and departure times

3. **Prepare Documentation**
   - Bring copy of authorization
   - Have client contact information
   - Carry company ID
   - Prepare access log

### During Visit

1. **Professional Entry**
   - Announce arrival (if client present)
   - Sign in (if required)
   - Display company ID
   - Access only authorized areas

2. **Maintain Boundaries**
   - Stay in authorized areas only
   - Don't access restricted spaces
   - Don't operate unauthorized equipment
   - Don't access client data systems

3. **Document Activity**
   - Note arrival and departure times
   - Record work performed
   - Photograph issues (if appropriate)
   - Document any problems

### After Visit

1. **Secure Property**
   - Lock all doors
   - Set alarms (if applicable)
   - Return all items to proper place
   - Verify property secured

2. **Client Notification**
   - Confirm completion (if required)
   - Report any issues discovered
   - Provide work summary
   - Schedule next visit (if applicable)

3. **Update Records**
   - Log the visit
   - Update client file
   - File any documentation
   - Report to management

## Keys, Codes, and Access Credentials

### Key Management

**Issuance**:
1. Client provides key or code
2. Key tagged with client name and location
3. Entry in key log with signatures
4. Key secured in locked cabinet
5. Copy of key log to client file

**Use**:
- Sign out before each use
- Sign in upon return
- Never duplicate without written permission
- Never share or lend
- Never take home unless explicitly approved

**Return**:
- Upon contract termination
- Immediately upon request
- When employee departs
- Signed receipt from client

### Access Codes

**Documentation**:
- Stored in [[Data Privacy Policy|highly sensitive]] location
- Access restricted to need-to-know
- Never written on key or public location
- Changed immediately if compromised

**Security**:
- Not shared with unauthorized persons
- Not stored on personal devices
- Not transmitted via unencrypted methods
- Changed periodically per client policy

## Unauthorized Access Situations

### What is Unauthorized Access?

- Accessing property without written authorization
- Entering restricted areas
- Operating unauthorized equipment
- Accessing before/after authorized times
- Allowing unauthorized persons access
- Using client resources for personal benefit

### If Unauthorized Access Occurs

**If you accidentally access something unauthorized**:
1. **Stop** immediately
2. **Exit** the area or stop the activity
3. **Report** to management immediately
4. **Document** exactly what happened
5. **Notify** client if appropriate

**If you witness unauthorized access**:
1. **Stop** the person if safe to do so
2. **Report** immediately to management
3. **Document** everything observed
4. **Preserve** any evidence

### Consequences
- First incident: Warning, retraining
- Pattern of violations: Suspension or termination
- Intentional violations: Immediate termination, possible legal action

## Special Situations

### Emergency Access

**Definition**: Unscheduled access due to urgent situation (fire, flood, security breach, etc.)

**Procedures**:
1. Verify this is a true emergency
2. Attempt to contact client first
3. Access only if pre-authorized for emergencies
4. Document everything
5. Notify client as soon as possible
6. File detailed report

### Client-Requested Changes

**If client requests access to unauthorized areas**:
1. Verify identity of requester
2. Document the request
3. Update authorization form (signed)
4. Update client file
5. Notify all relevant staff

**If client revokes access**:
1. Document the revocation
2. Return all keys/credentials immediately
3. Update client file
4. Notify all staff
5. Cease all access immediately

## Visitor and Guest Policy

### Bringing Visitors to Client Sites

**Generally prohibited** unless:
- Client pre-approves in writing
- Visitor has legitimate business need
- Visitor signs NDA (if applicable)
- Visitor has appropriate insurance
- Client is notified in advance

**Procedures**:
1. Request client permission
2. Provide visitor information
3. Receive written approval
4. Brief visitor on rules
5. Supervisor visitor at all times
6. Log visitor access
