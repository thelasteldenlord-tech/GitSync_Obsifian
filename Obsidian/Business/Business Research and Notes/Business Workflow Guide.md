Quick reference for common business processes and workflows.

## Client Onboarding Workflow

### 1. Initial Contact
- [ ] Log contact in [[Targeting as Potential Customers|Contact List]]
- [ ] Create contact note from [[Business Contact Template|Contact Template]]
- [ ] Schedule discovery call
- [ ] Send initial introduction email

### 2. Discovery & Qualification
- [ ] Conduct needs assessment
- [ ] Document requirements
- [ ] Assess fit and scope
- [ ] Provide ballpark estimate
- [ ] Send formal proposal

### 3. Contract & Setup
- [ ] Finalize scope of work
- [ ] Prepare contract/agreement
- [ ] Send and execute contract
- [ ] Set up project folder
- [ ] Create client folder in [[Clients/Current|Current Clients]]
- [ ] Onboard to communication channels

### 4. Project Kickoff
- [ ] Schedule kickoff meeting
- [ ] Document objectives and timeline
- [ ] Establish communication cadence
- [ ] Set milestones and deliverables

## Project Management Workflow

### Planning Phase
1. Define scope and objectives
2. Create project timeline
3. Identify resources needed
4. Set budget and billing structure
5. Document in project note

### Execution Phase
1. Regular status updates to client
2. Track progress against milestones
3. Document issues and resolutions
4. Update project notes weekly

### Completion Phase
1. Final deliverable review
2. Client approval/sign-off
3. Final invoice
4. Project retrospective
5. Request testimonial/referral
6. Move to [[Clients/Former|Former Clients]] if project complete

## Sales Cycle Workflow

### Lead Generation
- [ ] Identify potential client
- [ ] Research company/needs
- [ ] Find decision maker contact
- [ ] Initial outreach (email/LinkedIn)

### Nurturing
- [ ] Follow up within 2-3 days
- [ ] Share relevant resources
- [ ] Schedule call/meeting
- [ ] Present capabilities

### Proposal
- [ ] Understand specific needs
- [ ] Create custom proposal
- [ ] Present proposal
- [ ] Handle objections
- [ ] Negotiate terms

### Closing
- [ ] Send contract
- [ ] Address final questions
- [ ] Get signature
- [ ] Begin onboarding

**Timeline:** Track in contact note, typical cycle 2-8 weeks

## Marketing Content Workflow

### Planning
1. Identify topic/purpose
2. Define target audience
3. Choose format (blog, video, social)
4. Set publication date

### Creation
1. Research and outline
2. Create first draft
3. Source/create visuals
4. Review and edit
5. Finalize content

### Publishing
1. Upload to platform
2. Optimize (SEO, tags, etc.)
3. Schedule or publish
4. Share across channels
5. Track engagement

### Follow-up
- Monitor comments/engagement
- Respond to inquiries
- Document what worked
- Plan follow-up content

Store content plans in [[Marketing and Advertising|Marketing folder]]

## Networking Workflow

### Event Preparation
- [ ] Research attendees/speakers
- [ ] Prepare elevator pitch
- [ ] Set networking goals
- [ ] Bring business cards
- [ ] Review recent industry news

### At Event
- [ ] Introduce yourself to target contacts
- [ ] Listen actively, find common ground
- [ ] Exchange contact information
- [ ] Take brief notes after each conversation
- [ ] Follow up before leaving

### Post-Event
- [ ] Add contacts to [[Targeting as Potential Customers|Contact List]]
- [ ] Send personalized follow-up within 24-48 hours
- [ ] Connect on LinkedIn
- [ ] Schedule follow-up call if appropriate

## Idea Evaluation Framework

### Initial Assessment
1. **Market Need:** Does this solve a real problem?
2. **Differentiation:** What makes this unique?
3. **Resources:** Do we have capacity to execute?
4. **Profitability:** Can this generate revenue?

### Validation
- [ ] Research competitors
- [ ] Talk to potential customers
- [ ] Estimate costs
- [ ] Create basic business model

### Decision
- [ ] Document in [[Ideas and Pitch Decks|Ideas folder]]
- [ ] Decide: Pursue / Maybe Later / Archive
- [ ] If pursuing, create project plan
- [ ] Set timeline and milestones
